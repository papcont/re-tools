# re-tools

Werkzeuge und Notizen für Reverse Engineering mit REA + Ghidra in Claude-Code-Cloud-Sitzungen.

- `docs/handover.md` – Stand, Schritte und Stolpersteine
- `scripts/build-ghidra.sh` – Ghidra aus Quellcode bauen und bei REA registrieren
- `gradle/maven-mirror.gradle` – Maven Central über Googles Spiegel
