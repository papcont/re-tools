# re-tools

Werkzeuge und Notizen für Reverse Engineering mit REA in Claude-Code-Cloud-Sitzungen.

- `.claude/skills/reverse-engineer-anything/` – REA-Skill (aus `rea-agents` 6.7.0, MIT), wird in jeder Sitzung mit diesem Repo automatisch geladen
- `scripts/cloud-setup.sh` – Setup-Skript für die Cloud-Umgebung: installiert REA, registriert den MCP-Server `rea` und den Skill
